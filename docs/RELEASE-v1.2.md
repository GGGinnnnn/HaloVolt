# HaloVolt v1.2 — 轮询与联网查找驱动

## 新增

### 定时轮询开关与间隔

- 「通用 → 电量读取策略」新增「定时轮询电量」开关。
- 可设 5 / 10 / 15 / 30 / 60 / 120 分钟。
- 默认开启，保持原有自动刷新行为；关闭后只在你手动刷新或打开设置时读取。
- 仍然只在用户活动时轮询，空闲时静默；轮询可能让休眠外设短暂唤醒。

### 查找官方驱动（联网）

- 设备卡片新增「查找驱动」。
- 首次点击会明确提示：该功能需要联网；确认后用默认浏览器搜索该设备的官方驱动/网页驱动。
- HaloVolt 不上传设备名称、VID/PID 或使用数据，也不读取浏览器页面内容；搜索词由浏览器发送给搜索引擎。

## 重要边界：网页驱动不能自动回传电量

厂商网页通常通过 WebHID / 登录会话访问设备，权限属于当前浏览器页面；另一个桌面进程无法读取页面里的电量，不同品牌也没有统一接口。因此 v1.2 **不会抓取网页驱动里的电量**，只做“识别设备名称 + 打开官方驱动页面”。

HaloVolt 的电量仍来自本地协议：

- BLE Battery Service
- Logitech HID++
- 标准 HID Battery Strength
- Compx / Nordic 52840 2.4G
- DAREU EK75 的 HID feature

## 适用建议

- 想要“零打扰 / 不唤醒”：关闭轮询，使用缓存和手动刷新。
- 想要“更及时”：开启轮询，间隔 15–30 分钟；不需要时随时关闭。
- 想要查官方驱动/固件：用「查找驱动」，但不要期待网页里的电量自动同步回 HaloVolt。
